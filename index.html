About this Course

What is JavaScript?

JavaScript is a dynamic, interpreted and weakly typed programming language which was built with the purpose of running in host environments (e.g. inside of a webpage in the browser).

It can be present on any page you visit on the web. Even if you don't see it directly, JavaScript is often running behind the scenes to make the page interactive.

There are also lot of pages that use JavaScript frameworks like React, Angular, or Vue.js to build complex and interactive user interfaces.

What will you learn in this Course?

You will learn the fundamentals of JavaScript, including variables, data types, functions, control structures, and more. By the end of this course, you will be able to build dynamic and interactive web applications using JavaScript.

Course Prerequisites

  • Basic HTML and CSS knowledge (i.e. basic web development knowledge) is required
  • You DON'T have to be an advanced or expert web developer though
  • NO JavaScript knowledge is required at all.
